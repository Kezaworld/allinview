## What is stubbed (deliberately, not yet real)

- **StoreKit 2 purchase/restore** (`src/lib/storekit.ts`): buttons show the approved prices
  and return "not wired yet — charges nothing". Real wiring needs the native build + the
  existing App Store Connect products (com.allinview.app.monthly / .yearly) + In-App Purchase
  capability on com.allinview.app.
- **Native storage**: web build uses `localStorage`. The iOS build must swap this for
  Capacitor Preferences / SQLite (on-device, same manual-save rule).
- **Native local notifications**: web build asks browser permission and lists reminders
  in-app. The iOS build must use Capacitor LocalNotifications.
- **Feedback**: saved on-device only in this step (`allinview:feedback` in localStorage).
  No email, no upload, no backend endpoint yet — that is a later decision.
- **iOS platform folder**: `ios/` was NOT generated here (needs `npx cap add ios`, which
  is safe locally but was left for the native-build step so this step stays a clean web build).
  No Xcode project exists yet.
